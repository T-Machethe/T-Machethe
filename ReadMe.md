# Process Engineer & Plant Metallurgist | Industrial Data Science | Mineral Processing Analytics

## 💫 About Me

I am a Process Engineer and Plant Metallurgist working at the intersection of mineral processing, operational excellence, and data science.

My work focuses on transforming plant data into actionable insights that improve throughput, recovery, process stability, and operating efficiency. I develop practical analytics solutions that support decision-making in production environments, from daily operational reporting to advanced modelling and optimisation.

### What I Build

- Python applications for production tracking, metal accounting, and process monitoring
- Data pipelines that automate reporting and improve data visibility
- Power BI dashboards for KPI tracking, performance analysis, and operational decision support
- Statistical and machine learning models for process optimisation and forecasting
- Tools that improve data integrity, reconciliation, and plant performance monitoring

### Areas of Interest

- Machine learning in mineral processing
- Process optimisation and operational analytics
- Production forecasting and variability analysis
- Metal accounting and reconciliation systems
- Industrial data platforms and lightweight decision-support applications
- Advanced process control and digital transformation in mining
